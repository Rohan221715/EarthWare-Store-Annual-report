# 📊 EarthWare Store – Annual Sales Data Analytics Dashboard

An interactive **Sales Data Analytics Dashboard built using Microsoft Excel** to analyze annual sales performance, understand customer purchasing behavior, identify sales trends, and generate actionable business insights.

## 📌 Project Overview

The **EarthWare Store Data Analytics Project** focuses on transforming raw sales data into meaningful business insights through data cleaning, data processing, exploratory analysis, and interactive visualization.

The project uses Microsoft Excel's advanced analytical capabilities, including **Pivot Tables, Pivot Charts, calculated columns, and Slicers**, to create a dynamic dashboard that helps businesses monitor performance and make data-driven decisions.

## 🎯 Project Objectives

- Analyze annual sales performance and order trends.
- Understand customer purchasing behavior based on age and gender.
- Identify top-performing states and sales channels.
- Evaluate order fulfillment and cancellation patterns.
- Build an interactive dashboard for efficient business reporting.
- Generate actionable insights to support marketing strategies and business growth.

## ⚙️ Project Workflow

### 1. Data Cleaning

- Standardized inconsistent data entries, including gender categories.
- Handled missing and inconsistent values.
- Cleaned and formatted data to maintain accuracy and consistency.

### 2. Data Processing

- Created calculated columns for age-group segmentation, including Teenagers, Adults, and Seniors.
- Extracted months from date fields to support time-based analysis.
- Organized and structured the dataset for efficient reporting.

### 3. Data Analysis

- Used Pivot Tables to summarize and analyze sales and order data.
- Evaluated customer demographics and purchasing patterns.
- Analyzed state-wise sales and channel-wise order distribution.
- Examined order statuses to understand fulfillment performance.

### 4. Dashboard Development

- Designed an interactive dashboard using Pivot Charts and Slicers.
- Implemented filters for Month, Channel, and Category.
- Created dynamic visualizations that update according to the selected filters.
- Presented key business metrics in a single, easy-to-understand interface.

## 📈 Dashboard Features

| Visualization | Purpose |
|---|---|
| Orders vs. Sales | Compares sales revenue and order volume. |
| Male vs. Female | Displays the gender distribution of customers. |
| Order Status | Visualizes delivered, returned, cancelled, and refunded orders. |
| Top 5 States | Identifies the leading states by sales. |
| Age vs. Gender | Compares customer segments across age groups and gender. |
| Orders by Channel | Shows the contribution of different sales channels. |

### 🎛️ Interactive Filters

The dashboard includes three interactive slicers:

- **Month:** Filter sales and order performance by month.
- **Channel:** Analyze performance across individual sales platforms.
- **Category:** Explore sales across different product categories.

These filters allow users to explore the data dynamically and view specific business performance metrics.

## 💡 Key Business Insights

The dashboard helps identify:

- **Customer demographics:** Understand purchasing patterns across age groups and gender.
- **Geographical performance:** Identify states contributing significantly to sales.
- **Sales channel performance:** Compare orders across different online marketplaces.
- **Order fulfillment:** Monitor delivery, return, cancellation, and refund distributions.
- **Sales trends:** Compare sales and order volumes across selected periods.

These insights can help businesses refine marketing campaigns, target customer segments, and improve operational decision-making.

## 🚀 Getting Started

Follow these steps to explore the dashboard:

1. Download or clone this repository.
2. Open the Excel workbook in Microsoft Excel.
3. Navigate to the **Dashboard** worksheet.
4. Use the Month, Channel, and Category slicers.
5. Explore the updated charts and analyze the sales performance.

**Note:** Use the Excel workbook (`.xlsx`) to interact with the slicers and Pivot Charts.
